APPLICATION INFORMATION

Slave Address Selection
The VCNL36828P supports a smart dual slave address where the designer can change the slave address by swapping the SCL
and SDA pins, as shown in Table 1.

TABLE 1 - SLAVE ADDRESS TABLE

PIN 5          PIN 6           7 BIT SLAVE ADDRESS                  8 BIT SLAVE ADDRESS (WRITE)             8 BIT SLAVE ADDRESS (READ)
                                                                                       0xC0                                   0xC1
SCL            SDA                         0x60                                        0xA2                                   0xA3

SDA            SCL                         0x51

A smart dual slave address provides the flexibility for the designer to connect two devices from two different slave addresses
on the same I2C bus. Besides that, the two slave address options allow designers to select a different slave address if one is
used by the other slave devices on the same I2C bus in a single device application.
